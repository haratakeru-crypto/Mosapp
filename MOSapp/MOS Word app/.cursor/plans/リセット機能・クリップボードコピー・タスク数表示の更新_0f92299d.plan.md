# リセット機能・クリップボードコピー・タスク数表示の更新

## 概要

1. **リセットボタンの機能更新**: 既存のリセット機能を確認・改善
2. **問題文内の文字のコピー**: `MOS模擬アプリ正誤判定表251120_挿入入力のみ.csv`を使用したクリップボードコピー機能の確認・修正
3. **問題数の動的表示**: CSVファイルからプロジェクトごとのタスク数を読み込み、その数だけタスクボタンを表示

## 実装内容

### 1. リセットボタンの機能確認・更新

- [ ] `ResetProject`メソッドの動作を確認
- [ ] リセット後のWordドキュメント再読み込み処理を確認
- [ ] エラーハンドリングの改善（必要に応じて）

### 2. クリップボードコピー機能の確認・修正

- [ ] `LoadClipboardTargets`メソッドが正しいCSVファイル（`Reference/CSV/MOS模擬アプリ正誤判定表251120_挿入入力のみ.csv`）を読み込んでいるか確認
- [ ] CSVファイルのパスが正しいか確認（`Reference`フォルダと`References`フォルダの違いに注意）
- [ ] `SetTextWithUnderline`メソッドがクリップボード対象のタスクで正しく動作しているか確認

### 3. タスク数の動的表示実装

- [ ] `LoadCurrentProjectTasks`メソッドで、現在のプロジェクトのタスク数（`_tasks.Count`）を正しく取得しているか確認
- [ ] `UpdateTaskButtons`メソッドで、タスク数に応じてタスクボタンを表示/非表示にする処理が正しく動作しているか確認
- [ ] XAMLで固定定義されているタスクボタン（TaskButton1～TaskButton7）が、動的に表示/非表示されるようにする
- [ ] タスク数が7より多い場合の対応（ItemsControlへの移行を検討、または最大タスク数の確認）

## ファイル変更箇所

### `Views/UiTestAppBarWindow.xaml.cs`

- `LoadClipboardTargets`: CSVファイルパスの確認・修正
- `LoadCurrentProjectTasks`: タスク数の確認
- `UpdateTaskButtons`: タスク数に応じた表示/非表示の確認・修正
- `ResetProject`: リセット機能の確認・改善

## 注意事項

- CSVファイルのパスは`Reference/CSV/`（単数形）か`References/CSV/`（複数形）かを確認
- プロジェクトごとのタスク数はJSONファイルから正しく読み込まれているかを確認
