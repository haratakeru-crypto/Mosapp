# Wordアドイン「MOSデバッグ」タブをすぐ表示するためのプロンプト

## 背景

Word VSTOアドインの設定では、当初リボンにタブが表示されない問題がありました。現在は「**MOSデバッグ**」タブが表示される状態になっています。このドキュメントは、同じ環境を再現したり、AIや作業者に指示するときに使えるプロンプト（指示文）をまとめたものです。

### なぜ最初はタブが出なかったか（原因と経緯）

当初タブが表示されなかった主な要因は次のとおりです。

- **スタートアッププロジェクトの違い**  
  ソリューションのスタートアップが WPF アプリ（MOS Word app）のままだと、F5 で起動するのは採点アプリ側だけです。Word は別起動になるため、**VSTO アドインをデバッグビルドで読み込んだ Word** が起動せず、古いアドインや未更新のアドインが使われている状態になりやすいです。その結果、リボン（MOSデバッグタブ）が更新されず「タブが出ない」ように見えます。

- **古いアドインがキャッシュされていた**  
  一度インストールした VSTO アドインは、Word や ClickOnce のキャッシュに残ります。ビルドし直しても、**以前の .vsto / マニフェストがそのまま使われている**と、新しい Ribbon.xml が反映されず、タブが表示されないことがあります。

- **正しい手順が一度で伝わっていなかった**  
  「スタートアップを New_MOSWordVSTOAddIn にする」「タブが出ないときはアドインをアンインストールして最新 .vsto で再インストールする」といった手順が、最初のプロンプトでは省略されていたり、試行のなかで少しずつ明らかになりました。

**何回かプロンプトを投げて手順を繰り返した結果**、上記のとおり「VSTO をスタートアップに設定して F5 で Word を起動する」「必要ならアンインストール → 最新 .vsto で再インストール → Word 再起動」という流れが揃い、その手順で起動した Word では「MOSデバッグ」タブが表示されるようになりました。  
この md に書いたプロンプトは、その**最初から使えばタブがすぐ出るように整理した手順**です。

## すぐにタブを出したいときの指示（短い版）

以下をそのままプロンプトとして使えます。

```
WordのVSTOアドインで「MOSデバッグ」タブを表示させたい。

1. スタートアッププロジェクトを New_MOSWordVSTOAddIn に設定する
2. F5 でデバッグ実行し、Word を起動する
3. リボンに「MOSデバッグ」タブが出ることを確認する

タブが出ない場合は：
- 一度アドインをアンインストールする
- 最新ビルドの .vsto で再インストールする
- Word を起動し直す

確認方法：出力ウィンドウに [Ribbon] GetCustomUI called と [Ribbon] Ribbon_Load completed が出ていればリボン（MOSデバッグタブ）は有効。
```

## 詳細手順として渡すときの指示（コピー用）

```
## Wordアドイン「MOSデバッグ」タブ表示の手順

### 前提
- ソリューション: MOS Word app.sln
- リボン用VSTOプロジェクト: New_MOSWordVSTOAddIn（Ribbon.xml で「MOSデバッグ」タブを定義）

### 手順
1. Visual Studio で MOS Word app.sln を開く
2. ソリューションエクスプローラーで「New_MOSWordVSTOAddIn」を右クリック →「スタートアッププロジェクトに設定」
3. F5 でデバッグ開始 → Word が起動する
4. Word のリボンに「MOSデバッグ」タブ（「ヘルプ」の右隣）が表示されることを確認
5. 出力ウィンドウで次が出力されていれば成功：
   - [Ribbon] GetCustomUI called
   - [Ribbon] Ribbon_Load completed - MOSデバッグタブとコマンドフックが有効です

### タブが出ない場合
- Word を終了する
- アドインをアンインストール（COMアドインの一覧から削除、またはメインアプリの「VSTOアンインストール」等）
- New_MOSWordVSTOAddIn をリビルドし、生成された .vsto で再インストール
- Word を起動し直す
```

## 技術メモ（実装者・AI用）

- **タブ定義**: `New_MOSWordVSTOAddIn/Ribbon.xml` の `<tab id="tabMOSDebug" label="MOSデバッグ" insertAfterMso="Help">`
- **表示制御**: `Ribbon.cs` の `GetCustomUI` で上記 XML を返し、`Ribbon_Load` でリボンUIを保持
- **デバッグタブの表示**: `GetDebugTabVisible` は常に `true`（Release でもログ確認可能）
- **関連ドキュメント**: 同一フォルダの `VSTO_デバッグ手順.md` の「New_MOSWordVSTOAddIn でデバッグする場合」を参照
