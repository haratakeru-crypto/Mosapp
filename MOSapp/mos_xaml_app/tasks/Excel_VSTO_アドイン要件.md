# Excel VSTOアドイン開発要件

## プロジェクトの背景と目的

### 背景
現在、C#によるExcelファイル内容の静的解析（結果判定）を行っているが、MOS試験の特性上、「正しい手順（特定のボタンクリックなど）で行われたか」も評価対象とする必要がある。

**例**: 関数を手入力ではなく、リボンの「数式で使用」ボタンから入力したか

### 目的
Excel（およびWord, PowerPoint）の操作イベントをリアルタイムで監視し、特定のコマンド実行履歴をログに残すVSTOアドインを開発する。既存の採点アプリはこのログを参照して、「手順の正当性」を判定する。

## 概要

あなたはC#とVSTO (Visual Studio Tools for Office) のエキスパートです。
MOS模擬試験アプリのために、ユーザーの操作（ボタンクリック）を記録するExcelアドインを作成したいです。

以下の要件に基づいて、Visual Studioで実装可能な「Ribbon XML」と「C#のコールバックメソッド」のサンプルコードを提示してください。

## 要件

### 1. 目的
Excelの「数式」タブにある「数式で使用(NameUseInFormula)」ボタンが押されたことを検知する。

### 2. 動作
ボタンが押されたら、ユーザーのTEMPフォルダにある `mos_log.txt` に現在時刻と "NameUseInFormula Clicked" というテキストを追記する。

### 3. 重要な制約
ログ出力後、Excel本来の「数式で使用」のメニューが正常に開くようにする（機能を無効化しない）。

### 4. 対象バージョン
Excel 2016/2019/365

## 出力してほしいもの

1. **`Ribbon.xml`** の記述（customUIタグ、commandsタグ部分）
2. **`Ribbon.cs`** (または `ThisAddIn.cs`) に記述するコールバック関数 (`onAction` 相当の処理)
3. **ログ書き込み部分のヘルパーメソッド**

## 実装上の注意点

- 既存のExcelの機能を無効化せずに、操作ログのみを記録する
- ログファイルのパスは `Path.GetTempPath()` を使用して取得
- ログファイルへの書き込みは排他制御を考慮する
- エラーハンドリングを適切に行う

## 実装方針（保留中）

### 推奨アプローチ
- **Application.CommandBars イベント + Ribbon XML** を組み合わせる
- Ribbon XML の `commands` タグで既存コマンドをフック
- `Application.CommandBars` のイベントを監視
- ログファイルに記録

### 実装の流れ
1. 新規VSTOアドインプロジェクトを作成
2. Ribbon XMLで既存コマンドをフック
3. コマンド実行を検知してログ記録
4. 既存の採点アプリがログを読み取る
