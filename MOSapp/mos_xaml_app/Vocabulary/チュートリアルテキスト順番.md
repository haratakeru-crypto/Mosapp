# チュートリアルのテキスト順番

タブ・ボタン（テーブル）と関数で、チュートリアルの文面は別です。追加や削除を伝えるときは、番号（T1、F1 など）を使ってください。

見出しはコーチマーク上部の太字です。

「両方」で開くと、先にタブ・ボタンの T1〜T7、そのあと関数の F1 です。
「タブ・ボタンだけ」は T1〜T7、「関数だけ」は F1 だけです。

## タブ・ボタン（テーブル）

| 番号 | 見出し | 本文 | 出るタイミング |
| --- | --- | --- | --- |
| T1 | チュートリアル | 問題文に出てくるキーワードがここに表示されます！ | 最初。問題文のキーワードを枠で示す。OK で次へ |
| 追加 | チュートリアル | すぐに分からなかった場合は「あとで見直す」ボタンを押してください。 | T1 の OK のあと　「あとで見直す」を策で示す。 |
| T2 | チュートリアル | ハイライトされたテーブルをクリックして選択してください。 | 「追加」の OK のあと |
| T3 | チュートリアル | リボンの『テーブルデザイン』タブをクリックしてください。 | テーブルを選択したあと |
| T4 | 正解です！ | 「テーブル」と問題文に出たらテーブルを選択して、「テーブルデザイン」タブを使います | テーブルデザインタブをクリックしたあと。画面中央の別ウィンドウ。文面は CSV 2行目の表示テキスト |
| T5 | チュートリアル | 正解です！こちらのOKボタンを押して次の問題に行きましょう！ | T4 と同時。T4 のウィンドウを枠で示す |
| T6 | チュートリアル | 正解したら次の問題に行きましょう！ | T4 の OK のあと。アプリの「次のキーワードへ」を枠で示す |
| T7 | チュートリアル | それでは、問題を解いてみましょう！ | T6 のクリックのあと。OK で閉じる |

T4 の本文は、他の正解文と同じ位置で改行されます。

```
「テーブル」と問題文に出たら
テーブルを選択して、「テーブルデザイン」タブを使います
```

### 位置が未保存のときだけ（T2 の前）

保存済みなら出ません。

| 番号 | 見出し | 本文 |
| --- | --- | --- |
| C1 | ハイライト位置の設定 | テーブルの『左上』の角をクリックしてください。 |
| C2 | ハイライト位置の設定 | 次にテーブルの『右下』の角をクリックしてください。 |
| C3 | ハイライト位置の設定 | 選択範囲が小さすぎます。左上と右下をもう一度クリックしてください。 |

C3 は、クリックした範囲が小さすぎたときだけです。

### グラフ用（いまの出題順には入っていない）

グラフをタブ・ボタンのチュートリアル対象にしたとき用です。いまの開始処理では、テーブルだけが対象です。

| 番号 | 見出し | 本文 |
| --- | --- | --- |
| G1 | チュートリアル（1/2） | ハイライトされたグラフをクリックして選択してください。 |
| G2 | チュートリアル（2/2） | リボンの『グラフのデザイン』タブをクリックしてください。 |
| GC1 | ハイライト位置の設定 | グラフの『左上』の角をクリックしてください。 |
| GC2 | ハイライト位置の設定 | 次にグラフの『右下』の角をクリックしてください。 |

## 関数

対象は CSV の最初の関数（最高）です。タブ・ボタンのような段階はありません。操作を案内する文面が1つだけ出ます。

| 番号 | 見出し | 本文 | 出るタイミング |
| --- | --- | --- | --- |
| F1 | チュートリアル | セルに「=MAX」と入力し、関数を選んで確定します。（正しい場所を操作すると次へ進みます） | 関数だけのときは最初。「両方」のときは T7 の OK のあと。前半は JSON の coachMessage |

正しく操作したあとの「正解！」は、クイズと同じで CSV 19行目の表示テキストです。チュートリアル専用の文面ではありません。

```
「最高」と問題文に出たら、
セルに「=MAX」と入力し、MAX関数を選んで確定します。
```
