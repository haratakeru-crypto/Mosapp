# Excel 類題作成 — Copilot 用プロンプト（Project3 配置別）

Microsoft Copilot に **コピペして使う** プロンプト集です。  
project3（タスク3-1〜3-7：印刷の向き・印刷範囲・印刷タイトル行・余白・改ページ・折り返し・メモ）の類題ブックを作成します。

**添付ファイル（推奨）:**
- `@task/Excel演習問題文一覧_操作手順.csv`（projectId=3 の行）

**問題文ファイル（完成初稿）:**
- [`task/MOS_類題_project3_配置別_5セット_問題文.md`](MOS_類題_project3_配置別_5セット_問題文.md) — 採点アプリ表示用（タスク3-1〜3-7 表記）
- [`task/類題Json/MOS_類題_project3_配置別_5セット_問題文.json`](類題Json/MOS_類題_project3_配置別_5セット_問題文.json) — パラメータ＋問題文
- [`task/類題Json/MOS_類題_project3_配置別_5セット_問題文_アプリ用.json`](類題Json/MOS_類題_project3_配置別_5セット_問題文_アプリ用.json) — `MOS演習問題文一覧.json` 形式

**禁止シート名（教材流用不可）:** `売上一覧` `販売実績` `スキルアップ検定結果`

**5セット差し替えマトリクス（3-1 / 3-4）:**

|--------|----------------|---------------------------|----------|
| 1 カフェ | 横向き | 縦（他シートも縦） | 広い |

## 0. 使い方（3セッション × 1セット）

```
1チャット = 1セット（§1〜§5 のいずれか1節のみ使用）
      ↓
セッション1 → 該当 § の「セッション1」プロンプト
      ↓  xlsx を保存
セッション2 → 同 § の「セッション2」プロンプト（xlsx 添付）
      ↓
セッション3 → 同 § の「セッション3」プロンプト（検証済みパラメータ表を貼る）
```

- **問題文はセッション3まで書かない**（セッション1はレイアウト仕様のみ）
- **操作種別を変更しない**（3-1=印刷の向き、3-4=余白プリセット、3-5=縦改ページ、3-7=メモ挿入）
- **3-1・3-4 は上表のセット別パラメータに従う**（全セット横／全セット広い、に統一しない）
- ブック名: `MOS_類題_project3_配置別_セット{N}_{テーマ}.xlsx`

## 共通 — セッション2 精査プロンプト（全セット共通テンプレ）

作成済み xlsx を添付し、以下を **セット番号・シート名・範囲を実ブックに合わせて** 実行する。

```text
あなたは MOS Excel 類題の検証担当です。
添付の xlsx（MOS_類題_project3_配置別_セット{N}_{テーマ}.xlsx）を開き、
以下のチェックリストで自己検証してください。問題文はまだ書きません。

【検証対象パラメータ（設計値・実ブックと照合）】
（§N の taskParams 表をここに貼る）

【検証チェックリスト — 各項目 PASS / FAIL】

| # | 検証項目 | 内容 |
|---|----------|------|
| V1 | 操作種別 | 3-1=印刷の向き、3-4=余白プリセット（広い/標準/狭い）、3-5=縦改ページ、3-7=メモ挿入 |
| V2 | シート名禁止 | 教材シート名（売上一覧・販売実績・スキルアップ検定結果）を使用していない |
| V3 | 範囲具体性 | 印刷範囲・印刷タイトル行・メモセル・折り返し範囲が実ブック上で特定できる |
| V4 | 3-1 向き | taskParams の orientation と一致（横セット: 対象のみ横・他縦 / 縦セット: 対象のみ縦・他横） |
| V5 | 3-2 印刷範囲 | 一覧タイトル行を除き「単価」相当列の最終データセルまで |
| V6 | 3-3 タイトル行 | 印刷タイトル行が設計行（例: 3:5）と一致 |
| V7 | 3-5 改ページ | 6月列までが1ページ目、7月列から2ページ目になる手動縦改ページ |
| V8 | 3-4 余白 | 設計の余白プリセット（広い/標準/狭い）と一致・他プリセットにしない |
| V9 | 3-7 メモ | 指定セルにメモ1件のみ・文言一致・他セルにメモなし |

【出力形式】

### 精査結果サマリー
- PASS: X / FAIL: Y

### 修正済みパラメータ表（印刷範囲・タイトル行・メモ文言を実ブックの値で確定）
| taskId | sheet | range/cell | parameter | 備考 |

【禁止】
- 問題文の生成
- 操作種別の変更
```

```text
あなたは MOS Excel 365 演習アプリの問題文ライターです。

【精査済みパラメータ表】
（セッション2の出力を貼る）

【文体ルール — 教材 project3 準拠】
- タスク3-1のみ導入文可（例: あなたは○○を管理しています。）
- 3-1: シート［○○］の印刷の向きを横向き／縦向きに設定します（taskParams の orientationJa に従う）
- 3-2: …のタイトルを除く「単価」の列の最終セルまでが印刷されるように設定します（単価列名はセット別）
- 3-3: …を印刷したときに、N～M行目が、すべてのページに印刷されるように設定します
- 3-4: 余白を「広い」／「標準」／「狭い」にします（taskParams の marginPresetJa に従う）
- 3-5: 改ページ位置を調整し、表の6月までが1ページ目、7月から2ページ目に印刷されるようにします
- 3-6: 表の１行目の文字の配置をセル内で折り返して表示されるように設定します
- 3-7: セル【○○】にメモを挿入し「"○○"」と入力します

【出力形式】
タスク3-1　…
タスク3-2　…
（7行）

【禁止】
- パラメータ表にない範囲・シート名
- 印刷タイトル列・横改ページ・セル結合の記述（3-5/3-6/3-7）
- ノート（セル内メモ）とコメント（メモ）の混同
```

```text
【レイアウト仕様 — 必ず遵守】
| 項目 | 値 |
|------|-----|
| 表開始セル | A3 |
| ヘッダー行 | 3行目 |
| 表形状 | 5列×25行（縦長） |
| シート数 | 4枚 |
| 列幅（文字数） | A:6, B:28, C:14, D:14, E:12 |
| 行高 | タイトル30 / ヘッダー26 / データ20 / 集計28 |
| 視覚要素 | 縦棒グラフ（日次売上補助シート） |
| 書式傾向 | 枠線なし＋交互薄ベージュ縞 |
| タブ色 | 8B5A2B（コーヒーブラウン系） |

   - 初期状態: 印刷の向きは縦、印刷範囲・印刷タイトル行は未設定

2. **店舗月次実績**（3-4, 3-5）

   - 6月列と7月列の境界で縦改ページが可能な列配置（7月＝9列目想定）
   - 余白は標準または狭いのまま（3-4で「広い」に変更）

3. **バリスタ検定結果**（3-6）
   - 表の1行目（ヘッダー行）: A5:L5 相当、長い見出しテキストで折り返し未設定
   - データ行は複数行

4. **日次売上補助**（補助シート）
   - 縦棒グラフ用の日次データ

【禁止】
- 教材シート名（売上一覧・販売実績・スキルアップ検定結果）
- 問題文の生成
- 操作種別の変更（3-4以外の余白変更、3-5以外の改ページ設定を済ませない）

【出力】
1. xlsx ファイル
2. Markdown のレイアウト仕様書（シート一覧・各タスクのセル範囲・印刷設計値）
```
