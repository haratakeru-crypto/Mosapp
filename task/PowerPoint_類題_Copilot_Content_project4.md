# PowerPoint Copilot 固定コンテンツ — Project4

Copilot への指示用固定文言です。再生成しても本ファイルは上書きされません。
各スライドの箇条書きは **一字一句そのまま** pptx に転記してください。

## フォーマット

- `### スライドN: タイトル` — タイトルは JSON の slideMap と一致させる
- `**箇条書き（そのまま転記）:**` — 3行以上必須
- スライド4 の図形内文言は JSON の targetPhrase と一致（箇条書きとは別）
- 図形・画像の配置は Copilot MD の「試験用レイアウト仕様」に従う（本ファイルには書かない）
