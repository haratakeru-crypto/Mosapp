# Word 類題作成 — Copilot 用プロンプト（Project6 配置別）

Microsoft Copilot に **コピペして使う** プロンプト集です。
project6 の類題文書（5セット×7タスク）を作成します。

**添付ファイル（推奨）:**
- `@task/Word問題文一覧_操作手順.csv`（projectId=6 の行）

**問題文ファイル（完成初稿）:**
- [`task/MOS_Word類題_project6_配置別_5セット_問題文.md`](MOS_Word類題_project6_配置別_5セット_問題文.md)
- [`task/類題Json/MOS_Word類題_project6_配置別_5セット_問題文.json`](類題Json/MOS_Word類題_project6_配置別_5セット_問題文.json)
- [`task/類題Json/MOS_Word類題_project6_配置別_5セット_問題文_アプリ用.json`](類題Json/MOS_Word類題_project6_配置別_5セット_問題文_アプリ用.json)

**禁止文字列（教材流用不可）:** `月別催事内容` `実施月` `富士の水だより` `北海道` `うまいもの市場` `最高売上` `平均売上` `合計売上`

**タスク6-1〜6-7 のパラメータ（セットごとに異なる）:**

| セット | 6-1表 | 6-2分割 | 6-3セル分割 | 6-5 | 6-7表 |
|--------|-------|---------|------------|-----|-------|
| 1 カフェ | 6×2 | 4行目分割 | 1行2列→2 | 列幅均等 | p1 11×4 |
| 2 医療 | 8×2 | 7行目分割 | 2行1列→4 | 列幅指定+行高 | p2 10×2 |
| 3 製造 | 5×3 | 3行目分割 | 1行3列→2 | 列幅均等 | p3 12×3 |
| 4 旅行 | 9×2 | 8行目分割 | 3行2列→5 | 列幅指定+行高 | p2 9×4 |
| 5 学習塾 | 7×3 | 6行目分割 | 2行2列→3 | 列幅均等 | p1 14×2 |

**注意:** 6-1は7行2列以外。6-2は5行目以外。6-3は1行2列目→3列以外。6-5は2セットが列幅cm指定＋行高統一。6-7は2ページ13行3列以外。

**Word UI パス（ビルド2508）:**

- 表変換: 挿入 → 表 → 文字列を表にする
- 表分割: レイアウト → 結合 → 表の分割
- 文字効果: ホーム → フォント → 文字の効果
- 列幅/行高: レイアウト → セルのサイズ → 列幅を揃える / レイアウト → セルのサイズ → 幅 / レイアウト → セルのサイズ → 高さ
- 表作成: 挿入 → 表

## 0. 使い方 — 完全 docx 作成（3セッション × 1セット）

**Copilot が空の骨組み docx を作るのを防ぐため、セッション1では (1) documentOutline の見出し1〜4＋本文を配置し、(2)「貼り付け用データ」ブロックをそのまま Word に入力してください。**

```
1チャット = 1セット（§1〜§5 のいずれか1節のみ使用）
      ↓
セッション1 → 該当 § の「セッション1」プロンプト（貼り付け用データを全転記）
      ↓  docx を保存
セッション2 → 同 § の「セッション2」プロンプト（docx 添付）
      ↓
セッション3 → 同 § の「セッション3」プロンプト（検証済みパラメータ表を貼る）
```

【セッション1で禁止 — ゴミデータ】
- 空の表・空セル・「xxx」「...」「ダミー」「サンプル」
- 行数だけ合わせた中身のない表
- Markdown テキストだけの回答（必ず .docx を保存）
- 受験者が行う操作の事前完了（6-4 文字効果、9-5 承認、10-1 置換 等）

【セッション1で必須 — 完全類題】
- 貼り付け用データのリテラルを**全セル・全段落に転記**
- テーマに沿った数値（売上・件数・出荷数等）をセットごとに異なる値で記入
- **操作の大分類を変更しない**（6-1=表変換、6-2=表分割、6-3=セル分割、6-4=文字効果、6-5=列幅均等または列幅指定＋行高、6-6=タイトル行、6-7=表作成）
