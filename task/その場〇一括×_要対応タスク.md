# その場〇／一括× になりやすいタスク — 要対応一覧

最終更新: 2026-09-24

## 背景

- **その場採点**（試験中・文書を開いたまま）では ○  
- **一括採点／復習**では ×  

になりやすいタスクを洗い出し、修正候補としてまとめる。

典型原因:

1. **最終文書状態が後続タスクで上書きされる** → 一括は証跡ログ頼み  
2. **ビュー／セッション状態が文書に残らない**（例: 編集記号の表示）→ 再オープンで消える  
3. **証跡必須**なのに VSTO 未準備・取りこぼしでログが無い  

パターン分類（参照用）:

| 型 | 説明 | 例 |
|----|------|-----|
| ビュー型 | 文書に残らない表示状態が採点条件 | Word 1-1 |
| 上書き＋証跡型 | 後続で見た目が消え、証跡で救済 | Word 4-5 / 5-1 / 7-1 / 7-3、PP 2-1 / 2-2 / 2-3 / 6-5 / 6-6 / 8-3 |
| 証跡必須型 | 最終状態があってもログ無しは × | Word 2-1 / 3-3 / 4-3 / 4-4 / 4-6 / 5-2 / 6-1 / 6-5 / 7-4 / 7-5 / 9-5 / 10-2 / 10-3、Excel 4-2 / 4-3、PP 8-5 |
