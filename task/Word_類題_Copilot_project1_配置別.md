# Word 類題作成 — Copilot 用プロンプト（Project1 配置別）

Microsoft Copilot に **コピペして使う** プロンプト集です。
project1 の類題文書（5セット×5タスク）を作成します。

**添付ファイル（推奨）:**
- `@task/Word問題文一覧_操作手順.csv`（projectId=1 の行）

**問題文ファイル（完成初稿）:**
- [`task/MOS_Word類題_project1_配置別_5セット_問題文.md`](MOS_Word類題_project1_配置別_5セット_問題文.md)
- [`task/類題Json/MOS_Word類題_project1_配置別_5セット_問題文.json`](類題Json/MOS_Word類題_project1_配置別_5セット_問題文.json)
- [`task/類題Json/MOS_Word類題_project1_配置別_5セット_問題文_アプリ用.json`](類題Json/MOS_Word類題_project1_配置別_5セット_問題文_アプリ用.json)

**禁止文字列（教材流用不可）:** `CSR活動のメリット` `社員のコンプライアンス意識の確立` `CSR活動の光と影` `会社の社会的責任` `ゼミ` `第１節　はじめに` `第２節 会社の社会的責任の定義と問題点`

**Word UI パス（ビルド2508）:**

- 編集記号: ホーム → 段落 → ¶（編集記号の表示/非表示）
- 箇条書き: ホーム → 段落 → 箇条書き
- スタイル: ホーム → スタイル
- 書式クリア: ホーム → フォント → すべての書式をクリア

## 0. 使い方（3セッション × 1セット）

```
1チャット = 1セット（§1〜§5 のいずれか1節のみ使用）
      ↓
セッション1 → 該当 § の「セッション1」プロンプト
      ↓  docx を保存
セッション2 → 同 § の「セッション2」プロンプト（docx 添付）
      ↓
セッション3 → 同 § の「セッション3」プロンプト（検証済みパラメータ表を貼る）
```

- **問題文はセッション3まで書かない**（セッション1はレイアウト仕様のみ）
- **操作の大分類を変更しない**（1-1=編集記号、1-2=箇条書き、1-3=スタイル適用、1-4=スタイル変更、1-5=書式クリア）
- 文書名: `MOS_Word類題_project1_配置別_セット{N}_{テーマ}.docx`

【レイアウト仕様 — 必ず遵守】
| 項目 | 値 |
|------|-----|
| セクション数 | 2 |
| 見出し構成 | 第1章 焙煎入門 / 第2章 衛生管理 |
| 余白 | 標準 |
| 印刷の向き | 縦 |
| スタイルセット | 基本（シンプル） |
| テーマカラー | 茶色 |
| 書式傾向 | 見出し下に薄茶背景＋下罫線点線 |
| 画像配置 | 本文右寄せ（エスプレッソマシン） |
| 改ページ位置 | 第1章末尾 |
| 印刷タイトル行 | なし（表なし） |
| 段落数（目安） | 28 |

【見出し構成】第1章 焙煎入門 / 第2章 衛生管理

   - 画像「エスプレッソマシン」を配置し、その**左**の段落に以下の文を配置

5. **1-5 書式クリア**
   - 見出し「第1章 焙煎入門」の下に「アラビカ種の特徴」を配置
   - 事前書式: 太字, 下線 を付与済み

【禁止】
- 教材の禁止文字列（CSR活動のメリット、社員のコンプライアンス意識の確立、CSR活動の光と影、会社の社会的責任、ゼミ 等）
- 問題文の生成
- 受験者が行う操作を事前に完了させない

【出力】
1. docx ファイル
2. Markdown のレイアウト仕様書（見出し一覧・各タスクの段落先頭文・画像名）
