# Excel 類題作成 — Copilot 用プロンプト（Project2 配置別）

Microsoft Copilot に **コピペして使う** プロンプト集です。  
project2（タスク2-1〜2-7：セルスタイル・インデント・中央配置・列幅保持貼り付け・取り消し線・結合解除・行削除）の類題ブックを作成します。

**添付ファイル（推奨）:**
- `@task/Excel演習問題文一覧_操作手順.csv`（projectId=2 の行）

**禁止シート名（教材流用不可）:** `下半期売上` `社員リスト` `担当者別売上` `業務予定` `参加者一覧`

---

## 0. 使い方（3セッション × 1セット）

```
1チャット = 1セット（§1〜§5 のいずれか1節のみ使用）
      ↓
セッション1 → 該当 § の「セッション1」プロンプト
      ↓  xlsx を保存
セッション2 → 同 § の「セッション2」プロンプト（xlsx 添付）
      ↓
セッション3 → 同 § の「セッション3」プロンプト（検証済みパラメータ表を貼る）
```

- **問題文はセッション3まで書かない**（セッション1はレイアウト仕様のみ）
- **操作種別を変更しない**（2-4=列幅保持貼り付け、2-5=取り消し線、2-7=行削除）
- ブック名: `MOS_類題_project2_配置別_セット{N}_{テーマ}.xlsx`

---

## 共通 — セッション2 精査プロンプト（全セット共通テンプレ）

作成済み xlsx を添付し、以下を **セット番号・シート名・範囲を実ブックに合わせて** 実行する。

```text
あなたは MOS Excel 類題の検証担当です。
添付の xlsx（MOS_類題_project2_配置別_セット{N}_{テーマ}.xlsx）を開き、
以下のチェックリストで自己検証してください。問題文はまだ書きません。

【検証対象パラメータ（設計値・実ブックと照合）】
（§N の taskParams 表をここに貼る）

【検証チェックリスト — 各項目 PASS / FAIL】

| # | 検証項目 | 内容 |
|---|----------|------|
| V1 | 操作種別 | 2-4=列幅保持貼り付け、2-5=取り消し線、2-7=行削除（結合・列削除でない） |
| V2 | シート名禁止 | 教材シート名（下半期売上・社員リスト等）を使用していない |
| V3 | セル範囲具体性 | 問題文用の全範囲が実ブック上で特定できる（曖昧表現なし） |
| V4 | セルスタイル名 | ［セルのスタイル］ギャラリーに実在する名称のみ（創作禁止） |
| V5 | 2-4 列幅差 | コピー元（右・広）と貼り付け先（左・狭）で列幅が異なる設計 |
| V6 | 2-5 範囲厳格 | 時間列の上下1行は取り消し線なし |
| V7 | 2-7 行数 | 削除対象2名がデータに存在、削除前22行・削除後20行 |
| V8 | 2-2 インデント | 対象範囲の直上・直下セルはインデント0、本体は2文字分 |

【出力形式】

### 精査結果サマリー
- PASS: X / FAIL: Y

### 修正済みパラメータ表（セル範囲・スタイル名・氏名を実ブックの値で確定）
| taskId | sheet | range/cell | styleOrNames | 備考 |

【禁止】
- 問題文の生成
- 操作種別の変更
```

```text
（セッション2の出力を貼る）

【文体ルール — 教材 project2 準拠】
- タスク2-1のみ導入文可（例: あなたは○○を管理しています。）
- セル: 【B24】、範囲: 【B6:B29】
- 2-1: 「○○」のセルのスタイルを設定 / セルのスタイル「○○」を設定
- 2-3: セル【A2】の文字の配置をセル範囲【A2:H2】の中央にします
- 2-4: 「表名」の表に、セル範囲【H…】をコピーし、列幅を保持して貼り付けます
- 2-5: セル範囲【…】の時間に、取り消し線を設定します
- 2-6: 表のタイトル「…」のセルの結合と文字列の配置を解除します
- 2-7: 表から「氏名」が「○○」と「○○」の行を削除します（スペース入り氏名）

【出力形式】
タスク2-1　…
タスク2-2　…
（7行）

【禁止】
- パラメータ表にない範囲・シート名
- 貼り付けオプション［値］等の記述（2-4は列幅保持のみ）
- セル結合・列削除の記述（2-5/2-7）
```

### セッション1 — レイアウト仕様書の作成

```text

【ブック名】MOS_類題_project2_配置別_セット1_カフェ.xlsx
【テーマ】カフェ（メニュー売上・パートスタッフ・店舗経費）

【レイアウト仕様 — 必ず遵守】
| 項目 | 値 |
|------|-----|
| 表開始セル | A3 |
| ヘッダー行 | 3行目 |
| 表形状 | 5列×20行（縦長） |
| シート数 | 6枚 |
| 列幅（文字数） | A:6, B:28, C:14, D:14, E:12 |
| 行高 | タイトル30 / ヘッダー26 / データ20 / 集計28 |
| 視覚要素 | 縦棒グラフ（メニュー売上シート） |
| 書式傾向 | 枠線なし＋交互薄ベージュ縞 |
| タブ色 | 8B5A2B（コーヒーブラウン系） |
| 印刷 | 縦向き |

【必須シートとタスク用データ要件】

1. **メニュー売上**（2-1）
   - ドリンク・軽食の売上表（20行データ＋小計行）
   - セル【B24】に小計または集計ラベル（2-1のスタイル適用先）
   - ギャラリーに「良い」スタイルが存在すること（未適用のまま）

2. **パート名簿**（2-2, 2-3）
   - 行2にタイトル【A2】（未中央配置）
   - B列に氏名リスト（データ行 B6:B29、B5は見出し・B30は空行、インデント0）
   - 2-2用: B6:B29 はインデント0、見出し・末尾はインデント0

3. **店舗別経費**（2-4）
   - 左側 A4:D13: 列幅狭い空き領域（貼り付け先）
   - 右側 H4:K13: 列幅広いコピー元（表「店舗別経費一覧」）
   - 同一シート内で列幅が H>K列 > A>D列 になるよう設定

4. **仕入予定**（2-5）
   - C列に時間データ（C5:C11、形式 9:00 等）
   - C4・C12 は時間以外（取り消し線なし）

5. **体験会名簿**（2-6, 2-7）
   - 行2付近に結合＋中央揃え済みタイトル「体験会参加者名簿」
   - 「氏名」列ヘッダー、データ22行（削除対象: 黒田 美月、片岡 樹 を含む）

6. **日次売上推移**（補助シート）
   - 縦棒グラフ用の日次データ

【禁止】
- 教材シート名（下半期売上・社員リスト・担当者別売上・業務予定・参加者一覧）
- 問題文の生成
- 操作種別の変更

【出力】
1. xlsx ファイル
2. Markdown のレイアウト仕様書（シート一覧・各タスクのセル範囲・スタイル名・氏名リスト）
```
