# Excel 類題作成 — Copilot 用プロンプト（Project4 配置別）

Microsoft Copilot に **コピペして使う** プロンプト集です。  
project4（タスク4-1〜4-4：スパークライン・比較グラフ・合計グラフ・代替テキスト）の類題ブックを作成します。

**添付ファイル（推奨）:**
- `@task/Excel演習問題文一覧_操作手順.csv`（projectId=4 の行）

**問題文ファイル（完成初稿）:**
- [`task/MOS_類題_project4_配置別_5セット_問題文.md`](MOS_類題_project4_配置別_5セット_問題文.md)
- [`task/類題Json/MOS_類題_project4_配置別_5セット_問題文.json`](類題Json/MOS_類題_project4_配置別_5セット_問題文.json)
- [`task/類題Json/MOS_類題_project4_配置別_5セット_問題文_アプリ用.json`](類題Json/MOS_類題_project4_配置別_5セット_問題文_アプリ用.json)

**禁止シート名（教材流用不可）:** `上半期売上` `５年間売上` `下半期売上` `商品別売上`

**タスク種類の分散（5セット）:**
| タスク | セット1 | セット2 | セット3 | セット4 | セット5 |
|--------|---------|---------|---------|---------|---------|
| 4-1 スパークライン | 縦棒 | 勝敗 | 折れ線 | 勝敗 | 折れ線 |
| 4-2 グラフ | 簇状縦棒 | 折れ線 | 面 | 横棒 | 3-D縦棒 |
| 4-3 グラフ | ドーナツ（下） | 横棒（上） | 3-D縦棒（左） | 面（左下） | ドーナツ（右上） |

---

## 0. 使い方（3セッション × 1セット）

```
1チャット = 1セット（§1〜§5 のいずれか1節のみ使用）
      ↓
セッション1 → 該当 § の「セッション1」プロンプト
      ↓  xlsx を保存
セッション2 → 同 § の「セッション2」プロンプト（xlsx 添付）
      ↓
セッション3 → 同 § の「セッション3」プロンプト（検証済みパラメータ表を貼る）
```

- **問題文はセッション3まで書かない**（セッション1はレイアウト仕様のみ）
- **操作の大分類を変更しない**（4-1=スパークライン、4-2=2系列比較グラフ、4-3=合計グラフ＋配置移動、4-4=代替テキストのみ）
- **セットごとにグラフ種類は JSON の taskParams に従う**（全セット同一種類にしない）
- ブック名: `MOS_類題_project4_配置別_セット{N}_{テーマ}.xlsx`

## 共通 — セッション2 精査プロンプト（全セット共通テンプレ）

作成済み xlsx を添付し、以下を **セット番号・シート名・範囲を実ブックに合わせて** 実行する。

```text
あなたは MOS Excel 類題の検証担当です。
添付の xlsx（MOS_類題_project4_配置別_セット{N}_{テーマ}.xlsx）を開き、
以下のチェックリストで自己検証してください。問題文はまだ書きません。

【検証対象パラメータ（設計値・実ブックと照合）】
（§N の taskParams 表をここに貼る）

【検証チェックリスト — 各項目 PASS / FAIL】

| # | 検証項目 | 内容 |
|---|----------|------|
| V1 | 操作種別 | 4-1=スパークライン6本、4-2=2系列比較グラフ、4-3=合計グラフ、4-4=代替テキストのみ |
| V2 | シート名禁止 | 教材シート名（上半期売上・５年間売上・下半期売上・商品別売上）を使用していない |
| V3 | 範囲具体性 | スパークラインのソース/配置範囲・グラフ用データ範囲が実ブック上で特定できる |
| V4 | 4-1 スパークライン | 種類=設計値（縦棒/勝敗/折れ線）、データ源=6か月分、配置範囲が設計と一致、未挿入の初期状態 |
| V5 | 4-2 比較グラフ | 種類=設計値（簇状縦棒/折れ線/面/横棒/3-D縦棒）、2系列・表データから作成 |
| V6 | 4-3 合計グラフ | 種類=設計値（円以外）、凡例に項目名表示、配置起点セルが設計と一致 |
| V7 | 4-4 既存グラフ | 対象シートに指定種類のグラフが事前配置済み、代替テキストは未設定 |
| V8 | 操作混同なし | 4-4でグラフ新規作成しない、4-1の種類が設計と異ならない |

【出力形式】

### 精査結果サマリー
- PASS: X / FAIL: Y

### 修正済みパラメータ表（範囲・列名・代替テキストを実ブックの値で確定）
| taskId | sheet | range/column | parameter | 備考 |

【禁止】
- 問題文の生成
- 操作種別の変更
```

```text
（セッション2の出力を貼る）

【文体ルール — 教材 project4 準拠】
- タスク4-1のみ導入文可（例: あなたは○○の売上実績データを集計しています。）
- 4-1: セル範囲【○○】に、データ範囲【○○】をもとに、縦棒/勝敗/折れ線のいずれかのスパークラインを挿入（種類を明示）
- 4-2: セル範囲【○○】のデータをもとに、○○ごとに20XX年度と20YY年度の売上を比較する○○グラフを作成（簇状縦棒/折れ線/面/横棒/3-D縦棒）
- 4-3: セル範囲【○○】を項目、【○○】を値とする○○グラフを作成（円以外）。凡例は○○名を表示し、グラフをセル【○○】を起点に表の下/上/左側/シート右上へ移動
- 4-4: シートに複数グラフがある場合は種類を明示（例: 縦棒グラフ、円グラフ）し、代替テキスト「"○○"」を追加します

【出力形式】
タスク4-1　…
タスク4-2　…
（4行）

【禁止】
- パラメータ表にない範囲・シート名
- 4-4でグラフ作成の記述（代替テキスト追加のみ）
- 設計と異なるスパークライン種類・グラフ種類の記述
```
