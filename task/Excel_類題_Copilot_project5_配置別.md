# Excel 類題作成 — Copilot 用プロンプト（Project5 配置別）

Microsoft Copilot に **コピペして使う** プロンプト集です。
project5 の類題ブック（5セット×6タスク）を作成します。

**問題文ファイル（完成初稿）:**
- [`task/MOS_類題_project5_配置別_5セット_問題文.md`](MOS_類題_project5_配置別_5セット_問題文.md)
- [`task/類題Json/MOS_類題_project5_配置別_5セット_問題文.json`](類題Json/MOS_類題_project5_配置別_5セット_問題文.json)

**禁止シート名（教材流用不可）:** `売上実績` `商品別売上` `月別売上`

**グラフ要素の UI パス（ビルド2508）:**

- クイックレイアウト: グラフを選択 → グラフのデザイン → クイックレイアウト
- グラフスタイル: グラフを選択 → グラフのデザイン → グラフスタイル
- 色の変更: グラフを選択 → グラフのデザイン → 色の変更
- グラフタイトル: グラフを選択 → グラフ要素 → グラフタイトル
- データテーブル: グラフを選択 → グラフ要素 → データテーブル
- グリッド線: グラフを選択 → グラフ要素 → グリッド線
- 目盛り: グラフを選択 → グラフ要素 → 軸 → 目盛り
- 凡例: グラフを選択 → グラフ要素 → 凡例
- 軸のタイトル: グラフを選択 → グラフ要素 → 軸のタイトル

## 0. 使い方（3セッション × 1セット）

- 問題文はセッション3まで書かない
- 操作種別を変更しない（5-1=レイアウト+タイトル、5-2=スタイル+配色、5-3〜6=グラフ要素）
- ブック名: `MOS_類題_project5_配置別_セット{N}_{テーマ}.xlsx`

セッション2/3 は Project4 Copilot MD §0 の共通テンプレを流用し、下記 taskParams 表を貼る。
