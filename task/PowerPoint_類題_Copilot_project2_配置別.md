# PowerPoint 類題 Copilot 用 — Project2 配置別（5セット）

MOS本番相当の **完全な pptx** を作成するためのプロンプト集です。

**Project2 パラメータ一覧**

| セット | 2-1切替 | 2-2秒 | 2-4自動秒 |
|--------|------|------|------|
| 1 カフェ | プッシュ | 2秒 | 4秒 |
| 2 医療 | フェード | 4秒 | 6秒 |
| 3 製造 | 渦巻き | 5秒 | 7秒 |
| 4 旅行 | カバー | 2.5秒 | 8秒 |
| 5 学習塾 | 切り替え | 4.5秒 | 10秒 |

## §0b 5セット一括作成プロンプト

```text
PowerPoint Project2 の類題 pptx を5セット分まとめて作成してください。
各セットは独立したファイルとして保存します。

作成するファイル:
  - MOS_PowerPoint類題_project2_配置別_セット1_カフェ.pptx
  - MOS_PowerPoint類題_project2_配置別_セット2_医療.pptx
  - MOS_PowerPoint類題_project2_配置別_セット3_製造.pptx
  - MOS_PowerPoint類題_project2_配置別_セット4_旅行.pptx
  - MOS_PowerPoint類題_project2_配置別_セット5_学習塾.pptx

各セットについて、本ドキュメントの「セットN」セッション1プロンプトの仕様を厳守してください。
スライド番号・タイトル文字列・オブジェクト名はパラメータ表と完全一致させてください。
受験者が行う操作（非表示・ズーム・SmartArt色等）は事前に完了させないでください。
```

## セット1：MOS_PowerPoint類題_project2_配置別_セット1_カフェ.pptx

**テーマ:** カフェ / **色:** 茶、スライドの背景2 / **デザイン:** イオン

### プロンプト（セッション1：完全 pptx 作成）

```text
あなたは MOS PowerPoint 365 演習用の .pptx を作成するアシスタントです。
以下の仕様どおりに **完全なプレゼンテーション** を作成し、ファイルを保存してください。
骨組みのみ・空欄プレースホルダ・「ダミー」文字は禁止です。

【禁止語句】MOS合格対策、スプリット、ワイプアウト、黒板、ジャンプしてターン、今年度募集について 等

【導入】あなたはカフェのバリスタ研修ガイド資料を作成しています。

【デザイン】
- スライドサイズ: ワイド スクリーン (16:9)
- デザイン テーマ: イオン / バリアント: オフィス
- 色のテーマ: 茶、スライドの背景2
- フォント: メイリオ

【スライド構成 — すべて配置】
  - **スライド1**（タイトルとコンテンツ）: バリスタ研修ガイド
  - **スライド2**（タイトルとコンテンツ）: 研修の目的
  - ※ 2-6: 画像「バリスタ端末」「確認マーク」配置・アニメ未設定
  - **スライド3**（タイトルとコンテンツ）: 設備の基本
  - **スライド4**（タイトルとコンテンツ）: 抽出の手順
  - ※ 2-8: 図形「星」に軌跡未設定・円図形はアニメなし
  - **スライド5**（タイトルとコンテンツ）: 品質管理
  - **スライド6**（タイトルとコンテンツ）: 研修スケジュールについて
  - 項目Aの確認
  - 項目Bの確認
  - 項目Cの確認
  - ※ 2-7: 箇条書きアニメ効果「ひし形」未変更
  - **スライド7**（タイトルとコンテンツ）: 3Dモデル配置
  - ※ 2-5: 3Dモデル「地球儀」に「ターンテーブル」未設定
  - **非表示スライド（事前）**: なし

【受験者操作前 — 以下は未実施のまま】
- transitionsApplied: 未実施
- animationsApplied: 未実施
- autoAdvanceSet: 未実施

【問題文（参考・操作は受験者が実施）】
  - タスク2-1　すべてのスライドに、画面切り替え「プッシュ」を設定します。効果のオプションを「右から」にします。
  - タスク2-2　すべての画面切り替えの継続時間を2秒に設定します。
  - タスク2-3　スライド3、4、5に「フェード」の画面切り替え効果を設定します。
  - タスク2-4　すべてのスライドが、「4」秒後に自動で次のスライドへ進むように画面切り替えのタイミングを設定します。
  - タスク2-5　スライド６の3Ｄモデル「地球儀」に、アニメーション「ターンテーブル」を設定します。
  - タスク2-6　スライド2のバリスタ端末と確認マークの２つの画像が、スライドの右下からから登場するようにします。アニメーションの継続時間は「0.75"秒にします。
  - タスク2-7　スライド「研修スケジュールについて」の箇条書きに設定されたアニメーションの効果を「ひし形」に変更します。また、クリックするとすべて同時に動くようにします。
  - タスク2-8　スライド４の星の図形にアニメーションの軌跡「プラス」を設定します。円の図形にはアニメーションを設定しません。

ファイル名: MOS_PowerPoint類題_project2_配置別_セット1_カフェ.pptx
```
