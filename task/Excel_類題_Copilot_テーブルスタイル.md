# Excel 類題作成 — Copilot 用プロンプト（テーブルスタイルのみ）

Microsoft Copilot に **コピペして使う** プロンプト集です。  
第2段階（精査）で Python が行う検証ルールを、**Copilot 自身のチェックリスト** として組み込んでいます。

**対象:** 「テーブルに ○○ テーブルスタイルを設定する」類題だけ（縞模様・強調列・フィルター等は今回含めない）

**添付ファイル（推奨）:**
- `@task/Excel演習問題文一覧_操作手順.csv`
- `@task/MOS_許容テーブルスタイル一覧.csv`

---

## 0. 使い方（3セッション）

```
セッション1 → §1「パラメータ表作成」
      ↓
セッション2 → §2「精査」（同じ表を貼り直して実行）
      ↓
セッション3 → §3「問題文生成」（精査OKの表だけ貼って実行）
```

- **1セッション = 1プロジェクト**（例: プロジェクト1 のみ）。全10プロジェクトを一度に頼まない。
- グラフ・セル書式など **テーブルスタイル以外は今回出力しない**。

---

## 1. セッション1 — パラメータ差し替え表の作成

```text
あなたは MOS Excel 365 演習アプリ向けの類題（練習問題）設計者です。
今回は **テーブルスタイル名を差し替える類題** だけを扱います。

【添付】
- Excel演習問題文一覧_操作手順.csv
- MOS_許容テーブルスタイル一覧.csv

【スコープ】（以下を書き換えてから実行）
- プロジェクトID: 1
- 対象: project1.xlsx に相当する問題のみ
- 教材として扱う行: CSV のうち、問題文に「テーブルスタイル「」が含まれるタスクのみ
  （演習 Tab1 では主に projectId=1, taskId=3）

【やること】
添付 CSV から該当タスクを抽出し、**パラメータ差し替え表** だけを Markdown で出力する。
問題文（description）はまだ書かない。

【出力形式】

| projectId | taskId | sheetName | parameterType | textbook_allowlistId | textbook_style_ja | variant_allowlistId | variant_style_ja | swap_rule |
|-----------|--------|-----------|---------------|----------------------|-------------------|---------------------|------------------|-----------|

【差し替えルール】
1. variant_allowlistId は **必ず** MOS_許容テーブルスタイル一覧.csv の allowlistId から選ぶ
2. variant_style_ja は CSV の display_name_ja を **完全一致で** 転記（自分で色名+番号を組み立てない）
3. textbook と variant の allowlistId は **異なる** こと
4. 推奨: 系統も変える（例: 中間10 → 濃色11、中間10 → 中間2）
5. 禁止: 「青、テーブルスタイル（中間）11」など **許容リストに無い名称** の創作
6. 禁止: 色 + 「中間/濃色/淡色」 + 番号 を推測で新規合成すること

【許容リスト（再掲・この4つのみ）】
| allowlistId | display_name_ja |
|-------------|-----------------|
| TS-M10-ORANGE | オレンジ、テーブルスタイル（中間）10 |
| TS-D11-GREEN | 緑、テーブルスタイル（濃色）11 |
| TS-M2-BLUE | 青、テーブルスタイル（中間）2 |

【swap_rule 列の例】
- medium10_to_dark11
- medium10_to_medium2

【禁止】
- 問題文の生成
- 許容リスト外のスタイル
- 1ブック外の新規シート名の追加
- 縞模様・最初/最後の列強調・フィルターなどテーブルスタイル以外の類題
```

## 2. セッション2 — 精査（Python 第2段階相当の自己検証）

セッション1で出力された表を **そのまま貼り付けて** 実行する。

```text
あなたは MOS Excel 類題の **検証担当** です。
以下のパラメータ差し替え表を、添付「MOS_許容テーブルスタイル一覧.csv」と照合して精査してください。
問題文はまだ書きません。

【検証表（セッション1の出力をここに貼る）】
（貼り付け）

【検証チェックリスト — 各行について PASS / FAIL を判定】

| # | 検証項目 | 内容 |
|---|----------|------|
| V1 | allowlistId 存在 | textbook_allowlistId と variant_allowlistId が許容 CSV に存在 |
| V2 | 名称一致 | variant_style_ja が許容 CSV の display_name_ja と完全一致 |
| V3 | 創作禁止 | variant_style_ja が許容リスト外の文字列でない（部分一致でも NG） |
| V4 | 差し替え有効 | textbook_allowlistId ≠ variant_allowlistId |
| V5 | 教材整合 | projectId/taskId/sheetName が Excel演習問題文一覧_操作手順.csv の該当行と一致 |
| V6 | 操作種別 | parameterType が table_style のみ（縞模様・フィルター等を混ぜない） |
| V7 | シート名 | sheetName が教材問題文のシート名と一致（例: 試験結果） |

【出力形式】

### 精査結果サマリー
- 総行数: N
- PASS: X / FAIL: Y

### 行ごとの結果

| projectId | taskId | V1 | V2 | V3 | V4 | V5 | V6 | V7 | 総合 | 修正指示 |
|-----------|--------|----|----|----|----|----|----|----|------|----------|

### 修正済みパラメータ表（FAIL 行は修正した完全版）
（Markdown 表。FAIL が1件でもあれば修正版を必ず出力）

【FAIL 時の修正方針】
- V2/V3 NG → variant_allowlistId を許容リストから選び直し、display_name_ja を転記
- V4 NG → 教材と異なる allowlistId に変更
- 推測で新しいスタイル名を作らない。迷ったら TS-D11-GREEN または TS-M2-BLUE を使う

【禁止】
- 問題文の生成
- 許容リストへの新規スタイル追加
```

## 3. セッション3 — 問題文の生成

セッション2の **修正済みパラメータ表（総合がすべて PASS）** だけを貼る。

```text
あなたは MOS Excel 365 演習アプリの問題文ライターです。
精査済みパラメータ表に基づき、**問題文だけ** を JSON 形式で出力してください。

【精査済みパラメータ表】
（セッション2の修正済み表を貼る）

【文体ルール】
- 既存教材に合わせる: 「シート［○○］のテーブルにテーブルスタイル「△△」を設定します。」
- シート名は表の sheetName を［］で囲む
- スタイル名は表の variant_style_ja を「」で囲み、**一字一句変えない**
- 1タスク1操作（スタイル設定のみ）

【出力形式】JSON のみ

{
  "practiceVariant": 1,
  "scope": "table_style_only",
  "items": [
    {
      "projectId": 1,
      "taskId": 3,
      "sourceTaskId": 3,
      "allowlistId": "TS-D11-GREEN",
      "description": "シート［試験結果］のテーブルにテーブルスタイル「緑、テーブルスタイル（濃色）11」を設定します。"
    }
  ]
}

【禁止】
- パラメータ表にない projectId / taskId
- 許容リスト外のスタイル名
- 操作手順の記述
- 縞模様・強調列・フィルターなどスタイル設定以外の指示
```

## 5. よくある Copilot の誤りと対処

| 誤り | 対処 |
|------|------|
| 「青、テーブルスタイル（中間）11」を創作 | セッション2 の V3 で FAIL → TS-M2-BLUE 等に差し替え |
| 凡例・グラフの類題まで出す | 「テーブルスタイルのみ」と §1 冒頭を再強調 |
| 全プロジェクト一括 | projectId を1つに固定して新しいチャット |
| 問題文と表を同時生成 | セッションを分ける（§0 参照） |

---

## 6. 将来 Python 化する場合

セッション2 の V1〜V7 は `tools/validate_pv_table_style.py` に移植可能です。  
Copilot プロンプトの表形式・JSON 形式はそのまま入力スキーマとして使えます。
