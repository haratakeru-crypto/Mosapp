# MOSapp ブラウザリモート実行 — 実装手順書

外部講師が **MOSapp をダウンロードせず**、**ブラウザから演習できる**ようにするための実装手順です。  
推奨方式は **Azure Virtual Desktop（AVD）** 上で現行 MOSapp を動かし、ブラウザでリモート画面を表示する方法です。

## 1. 実現方式の概要

### 1.1 やること

```
外部講師のブラウザ
    ↓ HTTPS
AVD Web クライアント（または自社 Web ポータル → AVD）
    ↓
Azure 上の Windows VM
    └ MOSapp + Office + VSTO + 問題 JSON
```

- 講師 PC には **exe・VSTO・問題 JSON を配らない**
- MOSapp のコード改修は **不要**（クラウド VM に現行発行物を入れる）
- 「埋め込み」は **リモートデスクトップのストリーミング** で実現する

### 1.2 やらないこと

- Web ページの iframe に MOSapp 本体を直接埋め込む（技術的に不可に近い）
- Office Online への全面移植（Checker / VSTO の全面書き直しが必要）

実装開始前に以下を揃えます。

| # | 項目 | 備考 |
|---|------|------|
| 1 | Azure サブスクリプション | 課金・管理者権限 |

| 5 | VSTO アドイン | Excel / Word / PowerPoint 各 1 つ |
| 6 | 実装担当者 | Azure 管理者 + MOSapp 動作確認担当 |

## 3. フェーズ別実装手順

### フェーズ 0：パイロット計画

| 項目 | パイロット | 本番 |
|------|-----------|------|
| VM 台数 | 1 台 | 最大 30 台（自動スケール） |
| 利用者 | 社内 1〜2 名 → 外部講師 1 名 | 外部講師 最大 30 名 |
| 問題データ | サンプル / 類題のみ | 本番 JSON |
| 期間 | 1〜2 週間 | 講義シーズン |

### フェーズ 1：Azure 基盤の構築

#### 1-1. リソースグループ

```
Azure Portal → リソースグループ → 作成
  名前:     rg-mos-avd-japaneast
  リージョン: Japan East
```

#### 1-2. 仮想ネットワーク

```
仮想ネットワーク → 作成
  名前:           vnet-mos-avd
  アドレス空間:   10.0.0.0/16
  サブネット:     subnet-sessionhosts（10.0.1.0/24）
                  ※ AVD セッションホスト VM 用
```

#### 1-3. Azure Virtual Desktop の作成

Azure Portal で **Azure Virtual Desktop** を検索し、次の順で作成します。

**① ホストプール**

| 設定項目 | プレビュー用 | 本番用 |
|----------|-------------|--------|
| 名前 | `mos-preview-pool` | `mos-production-pool` |
| 種類 | Pooled | Pooled |
| 負荷分散 | Breadth-first | Breadth-first |
| 最大セッション数 | **1** | **1** |
| 検証環境 | はい（プレビューのみ） | いいえ |

> MOSapp は VSTO・COM・Win32 ウィンドウ制御を使うため、**1 VM = 1 講師** を推奨します。

**② アプリケーショングループ**

| 設定項目 | 値 |
|----------|-----|
| 種類 | Desktop（フルデスクトップ） |
| ホストプール | 上記プールに紐づけ |
| 表示名 | `MOS 演習（プレビュー）` / `MOS 演習（本番）` |

**③ ワークスペース**

| 設定項目 | 値 |
|----------|-----|
| 名前 | `mos-workspace` |
| アプリケーショングループ | プレビュー・本番を登録 |

---

### フェーズ 2：ゴールデン VM の作成と MOSapp インストール

#### 2-1. テンプレート VM の作成

```
仮想マシン → 作成
  OS:        Windows 11（または Windows 11 マルチセッション）
  サイズ:    Standard_D4s_v5（4 vCPU / 16 GB RAM）
  ネットワーク: subnet-sessionhosts
  名前:      vm-mos-golden
```

#### 2-2. VM へのソフトウェアインストール

RDP で VM に接続し、次の順でインストールします。

| 順 | ソフトウェア | 備考 |
|----|-------------|------|
| 1 | .NET Framework 4.8 | MOSapp 前提 |
| 2 | Microsoft Office | Excel / Word / PowerPoint（デスクトップ版） |
| 3 | VSTO ランタイム | Microsoft Visual Studio Tools for Office |
| 4 | MOSapp 発行一式 | 下記「2-3」参照 |
| 5 | AVD セッションホスト拡張 | イメージ化前にエージェント確認 |

#### 2-3. MOSapp 発行物の配置

**開発マシン（リポジトリ）で発行:**

```powershell
# リポジトリルートで実行
powershell -ExecutionPolicy Bypass -File .\Publish-MOSapp-Full.ps1
```

**発行先:** `MOSapp\MOSapp\publish\`（および `Application Files\` 配下）

**VM へコピーしてインストール:**

1. `publish` フォルダ一式を VM にコピー（Azure Files / Blob + スクリプト等）
2. 表紙用 setup または統合 setup を実行してインストール
3. 各 VSTO をインストール
   - Excel: `ExcelAddIn1.vsto`
   - Word: `New_MOSWordVSTOAddIn.vsto`（`Rebuild-And-Install-WordVSTO.ps1` で Release 登録済みのもの）
   - PowerPoint: `PowerPointAddIn1.vsto`

**発行フォルダに含まれるべきもの（`PUBLISH.md` 準拠）:**

- `MOSapp.exe`
- `MOSExcelMogiApp.exe`
- `MOS Word app.exe`
- `Mos PowerPoint Mogi App.exe`
- `References\JSON\`（各科目の問題文 JSON）
- 依存 DLL（例: `Newtonsoft.Json.dll`）
- `Assets\config.json`（任意）

#### 2-4. VM 内での動作確認

ゴールデン VM 上で **必ず** 次を確認してからイメージ化します。

| # | 確認項目 | OK 条件 |
|---|----------|---------|
| 1 | 表紙から 3 科目が起動する | 各 exe がエラーなく開く |
| 2 | 問題文 JSON が読み込める | 問題が表示される |
| 3 | Office が起動し AppBar と並ぶ | ウィンドウ配置が崩れない |
| 4 | VSTO がロードされる | 採点が動作する |
| 5 | Excel / Word / PowerPoint 各 1 プロジェクト | 採点まで完了 |

#### 2-5. 講師向けショートカット（推奨）

VM デスクトップに `MOSapp` のショートカットを配置するか、ログオン時に起動するバッチを用意します。

```batch
@echo off
start "" "C:\Program Files\MOSapp\MOSapp.exe"
```

（実際のインストールパスは環境に合わせて変更）

#### 2-6. VM のイメージ化と展開

```
1. VM 内で sysprep 実行（一般化）
2. Azure Compute Gallery にイメージを登録
3. ホストプールにセッションホスト VM を展開
   - パイロット: 1 台
   - 本番: 最大 30 台（スケーリング計画と連動）
```

### フェーズ 3：外部講師の認証（Entra ID B2B）

#### 3-1. ゲストユーザーの招待

```
Entra ID → ユーザー → 新しいユーザー → 外部ユーザーを招待
  メール:   講師のメールアドレス
  表示名:   講師名
  役割:     （必要に応じて）Desktop Virtualization User
```

#### 3-2. AVD アプリケーショングループへの割り当て

```
Azure Virtual Desktop → アプリケーショングループ
  → mos-preview-appgroup（プレビュー）
  → mos-production-appgroup（本番）
  それぞれにゲストユーザーを追加
```

#### 3-3. アクセス期間の管理

| タイミング | 作業 |
|-----------|------|
| コース開始前 | プレビュー用グループのみ割り当て |
| 本番講義期間 | 本番用グループを追加 |
| コース終了後 | ゲストアカウントを無効化 |

### フェーズ 4：ブラウザからの接続

#### 4-1. 講師に渡す URL

**Microsoft 公式 Web クライアント（推奨）:**

```
https://client.wvd.microsoft.com/arm/webclient
```

講師は招待メールのアドレスでログインし、ワークスペース内の **「MOS 演習（プレビュー）」** または **「MOS 演習（本番）」** をクリックします。

#### 4-2. 講師の操作フロー

```
1. 案内 URL をブラウザで開く
2. Microsoft アカウントでログイン（B2B 招待済みメール）
3. デスクトップ一覧から「MOS 演習」を選択
4. リモート Windows 画面がブラウザ内に表示される
5. デスクトップ上の MOSapp を起動
6. 科目（Excel / Word / PowerPoint）を選択して演習
7. 終了後はログオフ（セッションを閉じる）
```

#### 4-3. 自社 Web ポータルからの誘導（任意）

完全な iframe 埋め込みは制限が多いため、**新しいタブで AVD を開く**形を推奨します。

```
[自社サイト]
  ログイン（B2B 連携）
    → 「プレビュー演習を開始」ボタン
         → https://client.wvd.microsoft.com/arm/webclient へリンク
    → 「本番演習を開始」ボタン
         → 同上（本番用ワークスペース）
```

将来的に API 連携する場合は、Azure Virtual Desktop のフィード URL を動的に生成する方式も検討できます。

#### 4-4. リモートデスクトップアプリ（任意・画質重視）

ブラウザより操作性を重視する場合:

- [Windows App（AVD クライアント）](https://aka.ms/avdclients)
- Microsoft Remote Desktop

同じ Entra ID でログインします。

### フェーズ 5：プレビュー環境と本番環境の分離

| 環境 | ホストプール | 問題データ | 用途 |
|------|-------------|-----------|------|
| プレビュー | `mos-preview-pool` | 類題・1 セットのみ | 講師の事前確認 |
| 本番 | `mos-production-pool` | フル問題 JSON | 講義・演習 |

**問題データの切り替え方法（例）**

| 方式 | 説明 |
|------|------|
| A. VM イメージを分ける | プレビュー用 / 本番用で別ゴールデンイメージ |
| B. 起動スクリプト | VM ログオン時に Blob から JSON を同期（プレビュー用コンテナ / 本番用コンテナ） |
| C. 環境変数 | プールごとに `MOS_DATA_PATH` を設定 |

社外秘レベルが高い場合は **プレビューに本番全問題を載せない** 運用を推奨します。

### フェーズ 6：同時 30 人のスケーリング

#### 6-1. スケーリング計画

```
ホストプール → スケーリング計画 → 作成

  最小ホスト数:     0 または 2（待機用）
  最大ホスト数:     30
  スケールアウト:   接続要求に応じて VM 追加
  スケールイン:     アイドル時に VM 停止
  スケジュール:     講義時間帯のみ起動（コスト削減）
```

#### 6-2. VM サイズ

| 用途 | サイズ | スペック |
|------|--------|----------|
| 標準 | Standard_D4s_v5 | 4 vCPU / 16 GB |
| 重い場合 | Standard_D8s_v5 | 8 vCPU / 32 GB |

### フェーズ 7：セキュリティ設定（社外秘）

AVD セッションホストまたは RDP 設定で以下を適用します。

| 設定 | 推奨値 | 目的 |
|------|--------|------|
| クリップボードリダイレクト | **無効** | 問題文のコピー防止 |
| ドライブリダイレクト | **無効** | ファイル持ち出し防止 |
| プリンタリダイレクト | **無効** | 印刷による漏洩防止 |
| 画面ウォーターマーク | 有効（可能なら） | 講師 ID 表示 |
| セッション終了時 | 一時ファイル削除 | 演習ファイルの残存防止 |

**セッション終了スクリプト（例）**

ログオフ時に演習用一時フォルダを削除するスクリプトを GPO またはログオフスクリプトで実行します。

---

### フェーズ 8：クラウド上のデータ配置（推奨）

#### 8-1. 構成

```
Azure Blob Storage（暗号化）
  ├ container-preview/   … プレビュー用 JSON
  └ container-production/ … 本番用 JSON

Azure SQL / Cosmos DB
  └ 採点ログ・利用履歴
```

#### 8-2. VM 起動時の同期（方式 B を採用する場合）

1. VM ログオン時に PowerShell で Blob から JSON をダウンロード
2. `References\JSON\` 相当のパスに配置
3. ログオフ時に削除

問題 JSON を VM イメージに焼き込まないため、**更新が容易**です。

## 4. 講師向け利用マニュアル（配布用テンプレート）

以下をそのまま講師に配布できます。

---

### MOS 演習環境の使い方（外部講師向け）

**必要なもの:** インターネット接続、Web ブラウザ（Microsoft Edge または Google Chrome 推奨）  
**不要なもの:** MOSapp のインストール、Office のインストール（クラウド上で用意済み）

#### 手順

1. 案内メールの URL を開きます。  
   `https://client.wvd.microsoft.com/arm/webclient`
2. 招待されたメールアドレスでサインインします。
3. 「**MOS 演習（プレビュー）**」または「**MOS 演習（本番）**」をクリックします。
4. 画面に Windows デスクトップが表示されたら、**MOSapp** をダブルクリックします。
5. 科目（Excel / Word / PowerPoint）を選び、通常どおり演習します。
6. 終了したら、リモート画面の **スタートメニュー → ログオフ** でセッションを終了してください。

#### 困ったとき

| 症状 | 対処 |
|------|------|
| ログインできない | 招待メールのリンクからアカウントを承諾したか確認 |
| デスクトップが表示されない | 管理者に連絡（アクセス権の確認） |
| 画面が重い | 有線 LAN 推奨。改善しない場合は管理者に連絡 |
| 採点が動かない | 一度ログオフして再接続。改善しない場合は管理者に連絡 |

## 5. 検証チェックリスト

本番投入前に以下をすべて確認します。

### 5-1. インフラ

- [ ] プレビュープールに VM が展開されている
- [ ] 本番プールのスケーリング（最大 30）が設定されている
- [ ] B2B ゲストがアプリグループに割り当てられている
- [ ] ブラウザから Web クライアントに接続できる

### 5-2. MOSapp

- [ ] VM 内で表紙 → 3 科目が起動する
- [ ] 問題文 JSON が読み込める
- [ ] Excel / Word / PowerPoint 各 1 タスクで採点できる
- [ ] VSTO がロードされている（採点エラーが出ない）

### 5-3. セキュリティ

- [ ] クリップボード・ドライブリダイレクトが無効
- [ ] ログオフ後に一時ファイルが残らない
- [ ] プレビュー環境に本番全問題が入っていない（方針に応じて）

### 5-4. 外部講師パイロット

- [ ] 外部講師 1 名が B2B で接続できる
- [ ] プレビュー環境で操作・採点フローを確認できる
- [ ] 講師向けマニュアルで自力接続できる

## 6. トラブルシューティング

| 症状 | 想定原因 | 対処 |
|------|----------|------|
| デスクトップ一覧が空 | アプリグループ未割り当て | Entra ID でユーザー割り当てを確認 |
| Office は開くが採点不可 | VSTO 未インストール / Trust 未設定 | VM 内で VSTO を再インストール、信頼設定 |
| 問題文が表示されない | JSON 未配置 / Merge 漏れ | `References\JSON` の存在確認、`PUBLISH.md` 手順再実行 |
| ウィンドウ配置が崩れる | 解像度・DPI 差 | VM 解像度を 1920×1080 等に固定 |
| 接続が遅い | VM サイズ不足 / ネットワーク | D4s_v5 以上、有線推奨 |
| B2B ログイン失敗 | 招待未承諾 / MFA | 招待リンク再送、MFA 設定確認 |

## 9. まとめ

| 項目 | 内容 |
|------|------|
| 実現方法 | AVD 上の Windows VM で MOSapp を実行し、ブラウザでリモート画面を表示 |
| 講師に渡すもの | URL + B2B アカウントのみ |
| 講師に渡さないもの | exe、VSTO、問題 JSON |
| MOSapp 改修 | 不要（発行物を VM にインストール） |
| 事前確認 | プレビュー用ホストプールを本番と分離 |
| 30 人同時 | 1 人 1 VM、最大 30 台スケール |

この手順に沿って実装すれば、社外秘を守りながら外部講師にブラウザから MOS 演習環境を提供できます。
